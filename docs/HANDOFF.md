# Искра: контекст проекта для планирования

Сводка для другого ассистента или человека, который будет помогать с планом. Состояние на 2026-11-03, версия 0.3.0 (сборка 7).
Репозиторий: https://github.com/Expireduser-source/Iskra. Подробный аудит и архитектура лежат в `docs/AUDIT.md`, ручные проверки — в `docs/TESTING.md`.

## Что это
Android-компаньон «Искра»: анимированная 2D чиби-кошкодевочка поверх всех приложений. Голос и текст, долгая память,
устойчивый характер и эмоции, управление телефоном в рамках Android без root.
Целевое устройство — Xiaomi Redmi Note 14 (HyperOS, экран до 120 Гц).
Исходный прототип 0.1.1 был сделан в ChatGPT. Его проверили и переписали с нуля на Kotlin + Jetpack Compose.

## Требования владельца (не нарушать)
- Все чувствительные действия управляемы и прозрачны. Опасные действия выполняются только после подтверждения.
- Данные хранятся локально, разрешения минимальные. Должна быть кнопка «стереть всё». Ключи API хранятся в Android Keystore.
- Нельзя использовать личные или рабочие данные владельца без конкретной необходимости и отдельного разрешения.
- Нельзя утверждать, что что-то проверено, если это не запускалось.
- Не привязываться к одному вендору. Учитывать лицензии и стоимость. Без переусложнения.

## Архитектура (кратко)
- **`core`** — чистый Kotlin/JVM, покрыт тестами (50 штук):
  - LLM-провайдеры: OpenAI-совместимый и Anthropic, с вызовом инструментов;
  - агент и SafetyPolicy (SAFE / CONFIRM / FORBIDDEN, лимит действий);
  - личность (PersonaSpec), настроение (MoodEngine), стиль (StyleProfile);
  - память: SQLite-записи, лексический поиск, фильтр секретов, сжатие старых диалогов;
  - офлайн-парсер команд;
  - AvatarBrain — поведение и физика персонажа;
  - VoiceGate — логика отклика на имя;
  - TTS-клиенты: Yandex, ElevenLabs, OpenAI-совместимый.
- **`app`** — Android:
  - окно поверх приложений и служба переднего плана;
  - процедурная отрисовка на Canvas (сторонних ассетов нет);
  - AccessibilityService только для глобальных действий: «Домой», «Назад», шторка, блокировка, скриншот;
  - шифрование ключей в Keystore;
  - экран разрешений под HyperOS;
  - Vosk-слух и потоковый TTS.
- **Сборка** — GitHub Actions: каждый push в main публикует debug-APK как pre-release `build-N`. Подпись фиксированным debug-ключом, поэтому обновления ставятся поверх.

## Что уже есть
| Область | Состояние |
|---|---|
| Персонаж поверх экрана | Перетаскивание, бросок, падение, сон, 10 эмоций, облачко с репликами, тап/двойной тап/долгое нажатие |
| Пассивная жизнь (0.3) | Ходит, бегает, прыгает, сидит, лезет по боковому краю и висит, ползёт по верхнему краю, убегает за экран и выглядывает сбоку или сверху; брошенная в край — цепляется. Регулируется непоседливость |
| Частота кадров (0.3) | Кадр на каждое обновление экрана при движении, 60 в покое, 10 во сне. Режимы «Как у экрана», «60», «Экономия», замер реальной частоты в настройках |
| «Мозг» | Облачная LLM на выбор: OpenRouter, DeepSeek, OpenAI, Anthropic или свой сервер. Без ключа работают только команды и память |
| Команды без облака | Будильник, таймер, фонарик, громкость, открыть приложение, поиск, звонок (с подтверждением), навигация, скриншот |
| Слух (0.3) | Постоянное офлайн-распознавание Vosk small-ru (45 МБ, скачивается по кнопке). Отзывается на «Искра…», 6 с после ответа можно говорить без имени, есть «Искра, стоп». На паузе во время своей речи и при выключенном экране |
| Голос (0.3) | Нейро-TTS (Yandex SpeechKit, ElevenLabs, OpenAI, свой сервер) с движением рта под реальный звук; при ошибке — системный голос |
| Память и характер | Структурированная память с удалением; настроение затухает со временем; стиль меняется только по явной просьбе |

## Что НЕ проверено на устройстве
- Сборка проходит, все 50 тестов зелёные, но на Redmi Note 14 владелец тестирует сам.
- Известный отчёт владельца: ElevenLabs падал с «Invalid audio buffer size». В сборке 7 исправлено, повторно не проверено.
- Не проверены:
  - слух в фоне на HyperOS;
  - реальная частота 120 Гц (HyperOS может её снижать);
  - расход батареи;
  - реальные ключи Yandex и OpenAI;
  - как позы выглядят в движении на телефоне.

## Известные ограничения и компромиссы
- Свободная беседа требует интернета и платного ключа LLM. Локальной LLM нет: модели, которые тянет этот телефон (1–3B), слабо говорят по-русски.
- Постоянный слух заметно тратит батарею.
- Микрофон в фоне Android разрешает, только если службу запустили при открытом приложении.
- Слух работает, пока персонаж на экране.
- Персонаж нарисован кодом и выглядит просто. Замена на риг (Rive/Spine/Live2D) запланирована через тот же интерфейс AvatarPose.
- Нет чтения экрана, SMS и контактов — это сознательное решение ради приватности.

## Идеи на следующие версии (из AUDIT.md и обсуждения, не утверждены)
- Стриминг ответа LLM в TTS по предложениям, чтобы она начинала говорить быстрее.
- Свой голос: клонирование или дизайн голоса в ElevenLabs, либо самостоятельный хостинг Silero/XTTS.
- Красивый персонаж: Rive/Live2D-модель, больше поз, реакция на открытое приложение (по согласию).
- Офлайн-запасной «мозг» (маленькая локальная модель для простых реплик).
- Напоминания и расписание, навыки (погода, заметки), проактивные реплики с ограничением частоты.
- Release-подпись и стабильный канал обновлений; замер батареи и оптимизация слуха (сначала грамматика по имени, потом полное распознавание).

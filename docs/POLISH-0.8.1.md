# Искра 0.8.1 — внимание к маленьким вещам

## Что изменилось

- **«Удиви меня» / «Искорка дня».** Двенадцать коротких приглашений заметить что-то необычное или поиграть с воображением. Работают без интернета и ключей, только по просьбе. Три последних варианта не повторяются в текущем сеансе. Это заранее написанные игры, не ответы языковой модели.
- **Знакомство в чате.** Искра встречает своим рисунком; есть кнопки для маленькой игры и просмотра памяти. Подсказка объясняет, что доступно сразу, а что требует модели.
- **Чтение без борьбы с прокруткой.** Чат следует за растущим ответом. Ручная прокрутка останавливает слежение; кнопка возвращает к последней реплике. Голосовой ввод и отправка получили подписи для TalkBack.
- **Вежливые приветствия.** Самостоятельные реплики ждут разблокировки и не перебивают голосовой ввод. Отложенная реплика не расходует дневной лимит.
- **Остановка ответа.** Старые callbacks больше не должны возобновлять отменённую речь или сбрасывать состояние следующего запроса. При остановке только озвучки текст может продолжать поступать.
- **Удаление данных.** Очистка блокирует новые обращения, ждёт завершения отменённых операций и работы с голосовым кэшем, затем удаляет данные. Экран памяти обновляется после завершения.
- **Сохранность истории.** Сообщения удаляются при сжатии только после сохранения пересказа или явного ответа модели «НЕТ». Ошибки сохраняют исходный диалог; повторная попытка — не раньше чем через пять минут. Локальные команды не запускают сжатие в облаке.
- **Экономия CI.** Ветка проверяется по pull request, main — по push; тесты и debug-сборка используют один запуск Gradle.

## Проверено локально

- JDK 17, Android SDK 35: `:core:test :app:assembleDebug :app:lintDebug` — успешно.
- 139 unit-тестов, 0 ошибок и пропусков.
- Android Lint: 0 ошибок, 29 предупреждений, 1 информационное замечание.
- Собран `ru.iskra.app.debug`, версия `0.8.1-debug`, код 14.

## Что ещё требует телефона

Сборка и unit-тесты не подтверждают поведение HyperOS, микрофона, TalkBack, реальную задержку речи или внешний вид на устройстве. Проверки перечислены в `TESTING.md`. Статусы дорожной карты не повышаются до ✅ без проверки владельцем.

## Следующие идеи, пока без реализации

- Небольшие продолжения игр: Искра отвечает на придуманное название или замеченную деталь, сохраняя прозрачную границу между офлайн-заготовкой и моделью.
- Подборка любимых «искорок», которую владелец собирает сам; без серии посещений, требований внимания и уведомлений ради возврата.
- Настройка анимаций под системное уменьшение движения и проверка крупных шрифтов на Redmi Note 14.

Что она умеет

Сразу и без интернета

Будильники, таймеры, напоминания, которые переживут перезагрузку, заметки, погода, фонарик, приложения — просто скажи или напиши.

Установка за минуту

  1. Открой на телефоне Iskra.apk — это всегда самая новая версия.
  2. Открой скачанный файл. Если Android спросит — разреши установку из браузера.
  3. Искра познакомится с тобой за четыре коротких шага. Каждое разрешение можно пропустить.

Вопросы

Это правда бесплатно?

Да. Команды, память, заметки, напоминания и погода ничего не стоят. Бесплатный «мозг» OpenRouter — примерно 50 сообщений в день; платные сервисы — доли копейки за ответ, с дневными лимитами, которые задаёшь ты.

Безопасно ли ставить APK?

Код открыт, каждую сборку делает GitHub Actions из открытого репозитория, APK подписан ключом проекта. Рядом лежит контрольная сумма .sha256.

Какие данные уходят с телефона?

Только то, что нужно функции, которой ты пользуешься: сообщение — выбранной модели ИИ, текст ответа — облачному голосу, город — для погоды. Полная таблица — в политике конфиденциальности.

Она человек?

Нет — Искра программа с ИИ и честно скажет об этом, если спросить.

# Ручная проверка на телефоне (MVP)

Отмечай ✅/❌ и записывай модель/версию HyperOS. Всё, что ниже, **не проверено на реальном устройстве**.

## Установка и запуск
- [ ] APK ставится, приложение открывается, нет падения при первом запуске
- [ ] Повторный запуск после «Закрыть все» в недавних — история чата на месте

## Обновление поверх (данные сохраняются)
Обновление = установка нового APK **поверх** старого, без удаления. Подпись сборок одинаковая (общий debug-ключ),
поэтому Android ставит обновление и оставляет данные. При **удалении** приложения Android стирает всё: память,
переписку, ключи; облачной копии нет (`allowBackup=false`) — для переноса есть «💾 Сохранить копию».
- [ ] До обновления: в «Память» есть хотя бы 2 записи (скажи «Запомни, что я люблю чай»), в чате есть сообщения, сохранён ключ
- [ ] Поставить новую сборку поверх (открыть APK → «Обновить»), **не удаляя** старую
- [ ] После обновления: записи памяти на месте, история чата на месте, ключ сохранён («Ключ API сохранён…»), настройки те же
- [ ] Диагностика показывает новую сборку; в журнале сохранились события до обновления
- [ ] Если Android пишет «Приложение не установлено» / «конфликт пакетов» — НЕ удалять, сообщить (значит, сменилась подпись)

## Спецвозможности после обновления (1.1b)
- [ ] После обновления открыть Искру, подождать 2–3 с: если «Искра · управление» включена, но не работает — сверху жёлтое предупреждение
- [ ] «Открыть спецвозможности» → выключить и включить «Искра · управление» → вернуться: предупреждение исчезло, «Искра, домой» работает
- [ ] Диагностика → строка «Служба спец. возможностей»: «в настройках: вкл, у системы: активна, в приложении: подключена»
- [ ] В журнале есть «Служба спецвозможностей подключена системой» (и «отключила … unbind», если было отключение)

## Резервная копия (1.2)
- [ ] «Память» → «💾 Сохранить копию» → выбрать папку (например, Загрузки) → файл `iskra-backup-ГГГГ-ММ-ДД.json`
- [ ] Открыть файл в любом просмотрщике: есть `"format": 1`, память и настройки; **нет ключей API** и нет переписки
- [ ] Удалить одну запись памяти → «📂 Восстановить» → выбрать файл → диалог показывает, сколько записей сейчас и сколько будет, какие настройки изменятся
- [ ] «Отмена» — ничего не изменилось; повторно → «Заменить» — запись вернулась, ключи на месте
- [ ] Выбрать не тот файл (картинку/текст) → понятная ошибка, ничего не сломалось

## Замеры скорости (журнал, для этапа 2)
- [ ] После ответа с облачной моделью в журнале: «LLM ответ: N симв., X мс» и «TTS (…): начал говорить, X мс от конца команды (синтез Y мс)»
- [ ] В этих строках нет текста сообщений и ответов

## Персонаж поверх экрана
- [ ] Разрешение «Поверх других приложений» выдаётся, переключатель включает персонажа
- [ ] Персонаж виден поверх рабочего стола и других приложений
- [ ] Моргает, покачивается; через ~90 с без действий засыпает («z»)
- [ ] Перетаскивание пальцем; после отпускания падает вниз и останавливается на «полу»
- [ ] Резкий бросок → реакция «Ай! Я тебе не мячик!» в облачке, надутая мордочка
- [ ] Двойной тап → «Мрр…», смущение (румянец)
- [ ] Тап → открывается быстрый чат поверх текущего приложения
- [ ] Долгое нажатие → открывается главное окно
- [ ] Поворот экрана: персонаж остаётся в пределах экрана
- [ ] Экран выключен 10 мин → включён: персонаж на месте, анимация идёт
- [ ] Через 1–2 часа фоновой работы персонаж не пропал (с настройками HyperOS из вкладки «Разрешения»)
- [ ] Кнопка «Убрать с экрана» в уведомлении скрывает персонажа

## Команды без облака
- [ ] «поставь будильник на 7:30» — будильник появился в «Часах»
- [ ] «таймер на 1 минуту» — таймер запущен
- [ ] «включи фонарик» / «выключи фонарик»
- [ ] «открой телеграм» (и другие приложения по-русски), «открой камеру»
- [ ] «громче», «тише»
- [ ] «домой», «назад», «уведомления» — с включённой службой спец. возможностей; без неё — понятная подсказка
- [ ] «позвони 112» — появляется диалог подтверждения; «Отмена» — набор не открывается
- [ ] «запомни: я люблю чай» → видно во вкладке «Память», удаляется крестиком
- [ ] «запомни: мой пароль 1234» → отказ

## Облачная модель
- [ ] Неверный ключ → понятное сообщение, приложение не падает
- [ ] Нет интернета → понятное сообщение
- [ ] Свободная беседа на русском, ответы в характере, эмоция меняет мордочку
- [ ] «Засеки десять минут на чай» → модель вызывает таймер
- [ ] Сообщи факт о себе («меня зовут …») → модель сама сохраняет его (🤖 в «Памяти»)
- [ ] В новой беседе модель использует сохранённый факт
- [ ] «Отвечай короче» → ответы становятся короче и это сохраняется после перезапуска
- [ ] Кнопка «Стоп» прерывает долгий ответ

## Голос
- [ ] 🎤 → запрос разрешения микрофона → распознавание русской речи → ответ
- [ ] Ответ озвучивается; у персонажа двигается рот; озвучку можно выключить в настройках

## Постоянный слух (0.3)
- [ ] Настройки → Слух → «Скачать модель» (45 МБ) → «✅ Модель на телефоне»
- [ ] «Слушать постоянно» → запрос микрофона → Сохранить → в уведомлении «🎤 Слушаю…», в статус-баре зелёный значок
- [ ] «Искра, поставь таймер на 1 минуту» (одной фразой) → таймер ставится без касаний
- [ ] «Искра» → ушки встают сразу, ещё до конца фразы → «который час» без имени → ответ
- [ ] Через ~6 с после ответа можно ответить без имени; потом снова нужно имя
- [ ] Разговор рядом без слова «Искра» её не будит
- [ ] Она не реагирует на собственный голос во время ответа
- [ ] «Искра, стоп» и тап по ней во время речи прерывают ответ
- [ ] Экран выключен → слух на паузе (если не включено «при выключенном экране»)
- [ ] Кнопка «Не слушать» в уведомлении выключает слух
- [ ] «Искра, позвони маме» голосом при закрытом приложении → всплывает окно подтверждения
- [ ] Расход батареи за час со слухом (Настройки → Батарея) — записать цифру

## Нейроголос (0.3)
- [ ] Настройки → Голос → выбрать сервис, ключ → «▶ Проверить голос» → звучит новый голос, рот двигается в такт
- [ ] Неверный ключ → под кнопкой понятная ошибка, фраза всё равно звучит голосом Android
- [ ] Музыка в фоне приглушается, пока она говорит

## Движение и частота (0.3)
- [ ] Настройки → Движение → «Как у экрана»: строка «экран отдаёт ~120 кадров/с» (записать число)
- [ ] Бег и падение выглядят плавно; в режиме «Экономия» — заметно реже кадры
- [ ] За 5–10 минут (непоседливость «шустрая»): прыжки, сидит, лезет по краю и висит, ползёт по верху,
      убегает за край и выглядывает сбоку/сверху, потом возвращается
- [ ] Бросок в боковой край высоко над полом → цепляется; бросок вверх → повисает
- [ ] Когда она полностью за экраном, касания в этом месте проходят в приложение под ней
- [ ] Тап, когда выглядывает → пугается и выходит

## Приватность
- [ ] «Стереть всё» удаляет память, переписку и ключ
- [ ] После переустановки данные не восстанавливаются из облачной резервной копии

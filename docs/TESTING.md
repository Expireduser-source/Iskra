# Ручная проверка на телефоне

Две проверки:
- **Быстрая** (≤ 15 мин) — на каждой новой сборке.
- **Полная** (~1 ч + 1 ч в фоне) — перед релизом (тег `v*`) и после крупных изменений.

Этап 1 считается законченным, когда быстрая проверка проходит на 3 сборках подряд и Искра 1 час работает в фоне без падений.

Отмечай ✅/❌ и записывай номер сборки. Результат удобнее всего прислать отчётом диагностики: «📤 Отправить отчёт файлом».

**Две версии на телефоне.** Обе стоят рядом и не мешают друг другу:
| | debug | release |
|---|---|---|
| Пакет | `ru.iskra.app.debug` | `ru.iskra.app` |
| Название | «Искра β» | «Искра» |
| Откуда | каждый push в main, релиз `build-N` | тег `v*`, релиз `vX.Y.Z` |
| Подпись | debug-ключ из репозитория | ключ владельца (в секретах GitHub) |

У каждой версии свои данные, ключи API и свои разрешения. Данные между ними переносятся только через «Память → 💾 Сохранить копию / 📂 Восстановить». Ключи в копию не попадают, их нужно ввести заново.

## Быстрая проверка (≤ 15 мин)

**Перед началом.** Сборка поставлена **поверх** предыдущей, без удаления.
Если Android пишет «Приложение не установлено» или «конфликт пакетов» — не удаляй старую версию, сообщи: это значит, что сменилась подпись.

### 1. Запуск (1 мин)
- [ ] Приложение открывается без падения, история чата на месте.
- [ ] Настройки → 🩺 Диагностика:
  - версия и номер сборки — новые;
  - «Сборка и подпись»: для debug — «debug · ru.iskra.app.debug · debug-ключ», для release — «release · ru.iskra.app · release-ключ, SHA-256 AE:2D:A7:A1…».
- [ ] Примерно через 5 с после запуска в журнале есть «Данные: память N, реплик в переписке M». N и M такие же, как до обновления.

### 2. Оверлей (2 мин)
- [ ] Персонаж появляется поверх рабочего стола и машет рукой. Если включено «Живёт своей жизнью» — двигается.
- [ ] Вид как в настройках (по умолчанию «Живой риг»): моргает, дышит, уши и хвост шевелятся.
- [ ] Перетаскивание пальцем: после отпускания падает на «пол».
- [ ] Тап открывает быстрый чат, долгое нажатие — главное окно.

### 3. Слух (2 мин)
- [ ] В уведомлении «🎤 Слушаю…». Фраза «Искра, который час» без касаний даёт ответ.
- [ ] Через ~6 с после ответа можно продолжить без имени.

### 4. Один ответ с LLM и голосом (2 мин)
- [ ] «Искра, расскажи коротко, что ты умеешь» → ответ модели (не офлайн) озвучен выбранным голосом.
- [ ] В журнале есть «LLM: первая фраза через X мс» и «TTS (…): начал говорить, Y мс от конца команды». Запиши Y (цель этапа 2 — ≤ 2000 мс).
- [ ] Текст ответа в чате и облачко над Искрой появляются по фразам, вместе с голосом.

### 5. Спецвозможности (3 мин)
- [ ] После обновления HyperOS обычно выключает «Искра · управление». Тогда сверху баннер «Управление телефоном выключено».
- [ ] «Открыть спецвозможности» → включить → вернуться: баннер исчез.
- [ ] «Искра, домой» сворачивает на рабочий стол.
- [ ] Диагностика → «Служба спец. возможностей»: «вкл / активна / подключена».

### 6. Отчёт файлом (2 мин)
- [ ] Диагностика → «📤 Отправить отчёт файлом» → в чат. Приходит `iskra-diag-ДАТА_ВРЕМЯ.txt`.
- [ ] Ошибок (E) в журнале нет. Если есть — отчёт приложить к сообщению о проблеме.

## Полная проверка (~1 ч + 1 ч в фоне)

Сначала пройти быструю проверку, потом всё, что ниже.

### Release-версия (при выпуске тега)
- [ ] Release APK из релиза `vX.Y.Z` ставится **рядом** с debug: на рабочем столе две иконки, «Искра» и «Искра β».
- [ ] Диагностика release: «release · ru.iskra.app · release-ключ», SHA-256 начинается с `AE:2D:A7:A1`.
- [ ] Перенос данных:
  1. в debug «Память» → «💾 Сохранить копию»;
  2. в release «📂 Восстановить» → тот же файл → «Заменить»;
  3. память и настройки совпадают;
  4. ключи API ввести заново.
- [ ] В системных спецвозможностях две службы: «Искра · управление» и «Искра β · управление».
- [ ] Release-версия поставлена поверх предыдущей release-версии: данные на месте.

### Обновление поверх (данные сохраняются)
Подпись одинаковая, поэтому Android ставит обновление и оставляет данные.
При **удалении** приложения Android стирает всё: память, переписку, ключи. Облачной копии нет (`allowBackup=false`).
- [ ] До обновления: в «Памяти» ≥ 2 записи, в чате есть сообщения, сохранён ключ.
- [ ] После обновления:
  - память, чат, ключ и настройки на месте;
  - в журнале сохранились события до обновления;
  - в журнале есть «Данные: память N…», N то же.
- [ ] Через 5 с после запуска, ничего не трогая, в журнале строка «access: Через 5 с после запуска: в настройках …, у системы …, в приложении …».
- [ ] «Не нужно» на баннере спецвозможностей — больше не напоминает.

### Резервная копия (1.2)
- [ ] «💾 Сохранить копию» → `iskra-backup-ГГГГ-ММ-ДД.json`.
- [ ] В файле есть `"format": 1`, память и настройки. **Нет ключей API** и нет переписки.
- [ ] Удалить запись → «📂 Восстановить» → диалог показывает, сколько записей сейчас и сколько будет, и какие настройки изменятся.
- [ ] «Отмена» — ничего не изменилось. Повторно → «Заменить» — запись вернулась, ключи на месте.
- [ ] Не тот файл (картинка или текст) → понятная ошибка, ничего не сломалось.

### Отчёт диагностики
- [ ] «💾 В папку» сохраняет отчёт в выбранную папку.
- [ ] В файле нет ключей API и текста переписки.
- [ ] «Скопировать текстом» копирует последние 60 событий.

### Вид персонажа (4.1, 4.2)
- [ ] Настройки → Движение → «Вид»: риг / спрайты / старый вид → Сохранить → вид меняется.
- [ ] Риг: моргает, дышит, смотрит по сторонам; при беге и броске уши, хвост и хвостик волос раскачиваются и успокаиваются.
- [ ] Риг: эмоции плавно перетекают (радость, грусть, удивление, злость, смущение, задумчивость, сонная, хитрая).
- [ ] Риг: тап — машет; «Искра» — кивает; резкий бросок — качает головой.
- [ ] Сидит / спит / ждёт ответа (телефон в руках) — картинки-спрайты; переход мягкий, без мигания. Ноги на той же линии, голова того же размера.
- [ ] Спрайты: ходьба — 2 кадра, лёгкое дыхание в покое, смена эмоций без мигания.
- [ ] Диагностика → «Кадры/с у Искры»: стоит — «отрисовка ~30» (в «Экономии» ~24), идёт — до частоты экрана.
- [ ] В журнале «Риг загружен: 10 слоёв» и записи «Нет своей позы: …» (по одной на состояние).
- [ ] **Расход в покое:** 1 ч без зарядки, Искра на экране стоит на месте (непоседливость выключена) → Диагностика → «Расход в покое»: записать «батарея −X %/ч, CPU Искры Y %». Повторить для «Спрайты» и «Старый вид».

### Персонаж
- [ ] Моргает и покачивается. Через ~90 с без действий засыпает («z»).
- [ ] Резкий бросок → «Ай! Я тебе не мячик!», надутая мордочка.
- [ ] Двойной тап → «Мрр…», смущение.
- [ ] Поворот экрана: персонаж остаётся в пределах экрана.
- [ ] «Убрать с экрана» в уведомлении скрывает персонажа.
- [ ] Движение → «Как у экрана»: «экран отдаёт ~120 кадров/с». В «Экономии» кадры заметно реже.
- [ ] За 5–10 мин (непоседливость «шустрая»):
  - прыгает, сидит;
  - лезет по краю и висит, ползёт по верху;
  - убегает за край, выглядывает и возвращается.
- [ ] Бросок в боковой край высоко над полом → цепляется. Бросок вверх → повисает.
- [ ] Когда она за экраном, касания в этом месте проходят в приложение под ней.
- [ ] Тап, когда выглядывает → пугается и выходит.

### Команды без облака
- [ ] «поставь будильник на 7:30», «таймер на 1 минуту»
- [ ] «включи фонарик» / «выключи фонарик»
- [ ] «открой телеграм», «открой камеру»
- [ ] «громче», «тише»
- [ ] «домой», «назад», «уведомления». Без службы спецвозможностей — понятная подсказка.
- [ ] «позвони 112» → диалог подтверждения. «Отмена» — набор не открывается.
- [ ] «запомни: я люблю чай» → запись видна в «Памяти» и удаляется крестиком.
- [ ] «запомни: мой пароль 1234» → отказ.

### Облачная модель
- [ ] Неверный ключ и нет интернета → понятное сообщение, приложение не падает.
- [ ] Беседа на русском, ответы в характере, эмоция меняет мордочку.
- [ ] «Засеки десять минут на чай» → модель ставит таймер.
- [ ] «Меня зовут …» → модель сохраняет факт (🤖 в «Памяти»). В новой беседе использует его.
- [ ] «Отвечай короче» → действует и после перезапуска.
- [ ] Кнопка «Стоп» прерывает долгий ответ.

### Версия 1.0 (этап 5)
- [ ] На рабочем столе «Искра β» (debug) и, после релиза, «Искра».
- [ ] «Память → 🗓 Ежедневная копия → Включить: выбрать папку» (например, Documents/Iskra) → сразу появляется `iskra-backup-ДАТА.json`, строка «последняя …». На следующий день — второй файл; файлов не больше 7.
- [ ] Диагностика → «Падения: за 7 дней 0 · без падений N дн.» и «Ежедневная копия: в папку …».
- [ ] После аварийного закрытия (если случится) при открытии — баннер «Искра аварийно закрылась … 📤 Отправить отчёт».

### Навыки (этап 3)
- [ ] «Искра, напомни через 2 минуты проверить чайник» → «напомню … через 2 мин (в …)»; через 2 мин — уведомление «Искра напоминает» и голос, если она на экране.
- [ ] «Напомни в 7 вечера позвонить» (сказать днём) → на 19:00 сегодня. «Напомни завтра в 9 про встречу» → завтра 09:00.
- [ ] Перезагрузить телефон с напоминанием через 10 мин → приходит вовремя; в журнале «После перезагрузки: напоминаний 1, пропущено 0».
- [ ] Настройки → Напоминания: если «⚠️ может прийти позже» — «Разрешить „Будильники и напоминания“» → включить → «✅ точно в срок».
- [ ] «Запиши заметку: купить молоко» → вкладка «Память» → «📝 Заметки» → есть; «что в заметках» — читает; «удали последнюю заметку» — спрашивает подтверждение.
- [ ] «Запиши заметку: пароль 1234» → отказ.
- [ ] Настройки → Погода: город → «Найти город» → «Нашла: …» → Сохранить. «Какая погода», «погода завтра», «погода в Казани», «нужен ли зонт» — отвечает без облачной модели. Режим полёта → «нет интернета — погоду не узнать».
- [ ] Настройки → «Сама заговаривает: часто», тихие часы так, чтобы сейчас было не тихо → выключить экран на 3 ч / утром включить → облачко с приветствием; в журнале «Сама заговорила: MORNING/RETURN … (N за день)». В тихие часы — ни разу.
- [ ] «Сохранить копию» → в JSON есть `"notes"`; «Восстановить» показывает «Заметки: сейчас N → будет M».

### Голос и скорость (этап 2)
- [ ] Длинный вопрос («расскажи историю про кота») — голос начинается до того, как ответ дописан; паузы между фразами короткие (< 0,5 с).
- [ ] Повтори короткую команду дважды («таймер на минуту») — второй раз в журнале «TTS (…, из кэша)». Диагностика → «Кэш голоса»: растёт.
- [ ] Ключ модели заменить на неверный → понятное сообщение; следующий вопрос — ответ сразу, без ожидания («Облако пока недоступно…»); вернуть верный ключ → снова отвечает модель.
- [ ] Режим полёта → «Искра, который час» работает; вопрос модели — «Нет связи… Пока работаю без облака».
- [ ] Диагностика → «Слух»: «экономный…, распознавание работало X % времени». В тихой комнате X мал. «Искра, поставь таймер на минуту» одной фразой работает.
- [ ] Выключить «Экономный слух» → в журнале «Слух: полный…», всё работает как раньше.

### Голос и слух
- [ ] 🎤 в чате → распознавание → ответ. Озвучку можно выключить в настройках.
- [ ] Неверный ключ голоса → понятная ошибка, фраза звучит голосом Android.
- [ ] Музыка в фоне приглушается, пока она говорит.
- [ ] «Искра» → ушки встают ещё до конца фразы. Разговор рядом без имени её не будит.
- [ ] Не реагирует на собственный голос. «Искра, стоп» и тап во время речи прерывают ответ.
- [ ] «Не слушать» в уведомлении выключает слух.
- [ ] «Искра, позвони маме» при закрытом приложении → окно подтверждения.

### 1 час в фоне с выключенным экраном
1. Зарядить ≥ 50 %, отключить зарядку.
2. Включить оверлей и «Слушать постоянно».
3. Запомнить % батареи и время.
4. Выключить экран на 1 час, телефон не трогать.

После часа:
- [ ] Включить экран: персонаж на месте, анимация идёт, уведомление «🎤 Слушаю…» на месте.
- [ ] «Искра, который час» — отвечает (если слух при выключенном экране был выключен, слух вернулся после включения экрана).
- [ ] Отчёт файлом:
  - в журнале нет ошибок;
  - нет «Служба создана» посреди часа (это значило бы, что HyperOS убила и перезапустила службу);
  - «Группа ожидания Android» — «освобождено от ограничений» или «активное».
- [ ] Расход батареи за час: Настройки → Батарея → Искра. Записать % и общий расход.
- [ ] Повторить с включённым «Слушать и при выключенном экране», записать расход.

### Приватность
- [ ] «Стереть всё» удаляет память, переписку, ключ и журнал.
- [ ] После переустановки данные не восстанавливаются из облачной копии.

- [ ] Пустой чат: рисунок Искры и кнопка «Удиви меня» помещаются на экране; в быстром чате — компактное приветствие.
- [ ] В режиме полёта «Удиви меня», «Искра, удиви меня» и «Искорка дня» отвечают сразу. За 10 запросов нет повторов трёх последних фраз. Ключ не требуется.
- [ ] «Не удиви меня» и «Запомни: удиви меня» не запускают игру.
- [ ] Длинный потоковый ответ: последняя строка остаётся видна. Прокрутить вверх — новые фразы не тянут вниз. «К последнему сообщению» возвращает к концу.
- [ ] TalkBack произносит «Голосовое сообщение» / «Остановить запись» и «Отправить сообщение» для соответствующих кнопок.
- [ ] Нажать «Стоп» до первой фразы и сразу отправить новое сообщение: старая речь не начинается, новый запрос остаётся активным до своего завершения.
- [ ] Тап по персонажу во время потоковой речи останавливает озвучку до конца этого ответа; следующая фраза не включает её снова.
- [ ] Во время долгого ответа выбрать «Стереть всё»: дождаться завершения, убедиться, что память, заметки, напоминания, переписка и голосовой кэш пусты, ключи удалены. Поздний ответ не возвращает данные.
- [ ] Утром оставить экран блокировки включённым на 3 минуты, затем разблокировать: приветствие может появиться после разблокировки, если позволяют тихие часы и лимиты. На заблокированном экране проактивных реплик нет.
- [ ] Голосовой ввод одновременно с периодической проверкой проактивности: Искра дожидается окончания команды и не сбрасывает распознавание своей репликой.

## Для всех телефонов и людей — 0.9.0 (проверка на телефоне ещё нужна)

### Быстро (≈ 8 мин)
- [ ] Свежая установка или «Настройки → Пройти знакомство заново»: 4 шага, вверху «Шаг N из 4». «Пропустить» и «Назад» работают; «Разрешить» открывает нужный экран, после возврата шаг показывает «✓» или переключатель «Показать Искру на экране».
- [ ] Обновление поверх 0.8.x: знакомство **не** показывается, память и настройки на месте; бывший «Режим кадров» стал «Экономией» (Авто ← «Как у экрана», Сбалансированный ← «60», Батарея ← «Экономия»).
- [ ] «Настройки → Экономия»: по умолчанию «Авто», строка «Сейчас: …». Включить экономию энергии Android → в пределах нескольких секунд «Батарея (включена экономия энергии Android)», в журнале строка «Экономия: …».
- [ ] 120 Гц только в движении («Авто» / «Сбалансированный»): в настройках телефона частота экрана «Высокая/Динамическая». Искра стоит — Искра больше не держит весь экран на 120 Гц (проверить в «Диагностике», строка «Кадры/с у Искры», и по расходу ниже). Потянуть её — во время движения плавно; через ~1,5 с после остановки голос «за 120» снимается.
- [ ] «Разрешения» → карточка «Чтобы Xiaomi / Redmi / POCO не выгружал Искру»: кнопки «Автозапуск», «Батарея», «Другие разрешения» открывают экраны HyperOS; если экрана нет — открывается «О приложении», без падения.
- [ ] Подключить зарядку при включённом и разблокированном экране: облачко вроде «Мрр, подзарядка!» (не чаще раза в 3 ч, не в тихие часы, не при «Не заговаривать самой»).
- [ ] Включить светлую тему в системе: приложение светлое, всё читается; тёмная — как раньше.

### Доступность (≈ 10 мин)

- [ ] TalkBack на Искре поверх приложений: «Искра, анимированный персонаж»; в меню действий — «поговорить», «Погладить», «открыть приложение», «Убрать с экрана». Каждое работает.
- [ ] Озвучка ответов выключена → TalkBack сам читает её облачко. Включена → не читает дважды.
- [ ] Размер шрифта максимальный: чат, настройки, знакомство и разрешения без обрезанного текста.
- [ ] «Спецвозможности → Убрать анимации»: Искра не гуляет; «Спокойные движения» включены и недоступны, с пояснением.

## Для всех — 0.10.0 (проверка на телефоне ещё нужна)
Эмуляторы Android 8, 11 и 16 (английский и русский) CI проверяет сам: запуск, знакомство, все вкладки, Искра поверх домашнего экрана, «Поделиться → Искре», ярлык «Напомнить», тёмная тема, крупный шрифт, поворот. Скриншоты — в релизе `build-N` (`smoke-api*.zip`). На телефоне остаётся то, что эмулятор не умеет.

### Язык (≈ 4 мин)
1. **Настройки → «Язык · Language» → English**: весь интерфейс, уведомление «Iskra on screen», облачко — по-английски. Ярлыки на иконке — по языку телефона (на Android 13+ — как выбрано).
2. Напиши: `set a timer for 2 minutes`, `remind me in 10 minutes to stretch`, `note: buy milk`, `what's the weather in London` — всё без облака.
3. Android 13+: **Настройки телефона → Приложения → Искра → Язык** показывает тот же выбор; смени там на «Русский» — приложение переключится.
4. Слух по-английски: «Настройки → Слух» предлагает модель ~40 МБ; после скачивания «Spark, set a timer for one minute» работает. Верни «Как в телефоне».

### Бесплатный «мозг» (≈ 3 мин)
1. Режим «Без облака». **Настройки → «🆓 Бесплатный мозг» → Подключить бесплатно**: сначала объяснение (50 сообщений в день, бесплатные модели могут учиться на переписке), потом браузер с openrouter.ai.
2. Войди (Google или почта). Страница «Готово ✓» → «Вернуться в Искру» открывает Настройки: «Подключено ✓ Модель: …», выбран OpenRouter.
3. Напиши «Привет! Как дела?» — ответ модели. Ключ в журнале не виден (Диагностика → «Ключ мозга: сохранён, sk-…» замаскирован).
4. Если страница не вернула в приложение: «Не вышло? Войти с кодом» → вставь код со страницы → «Подключить».

### Быстрый доступ (≈ 4 мин)
1. Выдели текст в браузере → в меню «Спросить Искру» → карточка с текстом и кнопками; «В заметки» сохраняет заметку без облака; с «мозгом» — «Кратко» и «Переведи».
2. «Поделиться» из любого приложения → «Спросить Искру» — то же самое.
3. Задержи палец на иконке Искры: «Спросить», «Голосом» (микрофон включается сразу), «Напомнить» (текст напоминания уже в поле), «На экране» (показать/убрать).
4. Шторка → карандаш → перетащи плитку «Искра». Тап — Искра появляется/исчезает, подпись «на экране»/«скрыта».

### О приложении и обновления (≈ 2 мин)
1. **Настройки → О приложении**: версия, GPL, лицензии, Open-Meteo; «❤ Рассказать другу» — QR-код. Отсканируй вторым телефоном: открывается страница проекта.
2. Release-версия с GitHub: «Проверить сейчас» → «У тебя последняя версия (0.10.0)». В β-версии этого блока нет — так и задумано.
3. Новая иконка на рабочем столе — портрет Искры; в тематических иконках Android 13+ — силуэт.

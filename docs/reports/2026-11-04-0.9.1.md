# Искра 0.9.1 — расходы под контролем и быстрый Claude

Продолжение [0.9.0](2026-11-04-0.9.0.md). Самодостаточный отчёт для владельца и других ассистентов.

## Что сделано
### Контроль расходов на облако
Код: `core/usage/Usage.kt`, настройки — «Экономия → Лимиты и цены облака».
- **Счётчики за день:**
  - запросы к модели;
  - токены — из отчёта сервиса, а если сервис не сообщает, оценка по длине текста, помеченная «≈»;
  - символы облачного голоса — только те, что синтезировал сервис; фразы из кэша бесплатны.
- **Текст не хранится.** Сохраняются только числа (`usage` в настройках приложения).
- **Лимиты владельца** — запросы, токены и символы голоса в день, 0 = без лимита:
  - на 80 % — одно предупреждение в чате и облачком;
  - на 100 % — до полуночи ответы без модели (команды работают) и системный голос, с понятной фразой.
  - Поднять лимит и нажать «Сохранить» — облако возвращается сразу.
- **Цены владельца** за 1 млн входных и выходных токенов и за 1 млн символов голоса, валюта — своя. С ними появляется «≈ сумма за сегодня». Цены в коде не зашиты.
- **Учёт токенов в потоке:** для OpenAI, DeepSeek и OpenRouter поток просит `stream_options.include_usage`, поэтому токены точные. Для своего сервера параметр не отправляется, чтобы не получить отказ.
- **Где видно:** строка «Облако» в «Экономии» и в отчёте диагностики. Лимиты и цены входят в резервную копию.

### Потоковые ответы Claude (Anthropic)
- `AnthropicProvider.stream()` + `AnthropicStreamParser`: текст идёт в речь по мере прихода, как у OpenAI-совместимых сервисов.
- Вызовы инструментов собираются из `input_json_delta`.
- Ошибки потока классифицируются по типу: ключ, перегрузка, лимит. Нехватка денег до начала потока — «закончились деньги».
- Если сервер ответил обычным JSON, всё тоже работает.

### Подписи коммитов
С разрешения владельца пять коммитов 0.9.0 пересозданы так, чтобы GitHub показывал «Verified». Автор остался прежним (почта владельца), коммиттер — Claude с подписью.

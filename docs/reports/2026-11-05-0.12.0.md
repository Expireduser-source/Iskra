## Что изменилось для человека
1. **Без «мозга» Искра больше не глупая.** Точно считает («сколько будет двадцать пять умножить на четыре», «15% от
   2300», «корень из 144»), переводит единицы («5 миль в км», «100 фаренгейт в цельсии», «сколько унций в фунте»), знает
   время и даты («сколько дней до Нового года», «какой день недели будет 1 января», «какое число через 10 дней»),
   бросает монетку и кубик, выбирает за тебя, болтает (приветствие по времени суток, «как дела» по настроению, шутки,
   факты, поддержка, когда грустно), запоминает имя, город и день рождения, «забывает» по просьбе. Голосом тоже: Vosk
   пишет числа словами — Искра их понимает.
2. **«Мозг» на телефоне.** Модель Qwen (0,4 / 1,1 / 2,5 ГБ — по памяти телефона) скачивается один раз и думает прямо на
   процессоре телефона через llama.cpp: без интернета, без аккаунта, ничего не уходит с телефона. Отвечает, когда облака
   нет, и подменяет облако, когда оно недоступно (нет сети, кончились бесплатные сообщения).
3. **Облачный «мозг» умеет больше и меньше выдумывает.** Новые инструменты: калькулятор, даты, Википедия, курсы валют,
   поиск и «забыть» в памяти; на телефоне — заряд/сеть/память, событие в календаре, маршрут, музыка и пауза, подготовленное
   сообщение, ссылка. Подсказка модели учит говорить правду, проверять факты инструментом и уточнять неясное.
4. **Память находит по смыслу.** Русская морфология (Snowball) и ~45 групп синонимов на двух языках: вопрос «как зовут мою
   собаку?» находит «у владельца пёс Рекс», «my dog» — тоже. В каждый запрос попадают главное о владельце и два последних
   разговора.
5. **Надёжнее.** Занятая бесплатная модель передаёт сообщение запасной (двум другим, от других разработчиков); модели,
   которые «думают вслух», не зачитывают рассуждения; модель без инструментов всё равно отвечает; короткие сбои
   переживаются тихим повтором; при словах о кризисе — сразу номер помощи (112, 988 в США).

## Проверено (запускалось)
- `ISKRA_CORE_ONLY=1 ./gradlew :core:test` — **218 тестов, 0 ошибок** (было 183): офлайн-мозг, инструменты с
  MockWebServer (Википедия, курсы), память, подсказка, запасные модели, фильтр `<think>`, модель на телефоне с поддельным
  движком, подрезка диалога под контекст, день рождения из памяти.
- **Настоящий llama.cpp через JNI на компьютере**: та же C++-обвязка, что в приложении, собрана для Linux; крошечная
  модель Qwen2 (настоящий токенизатор, случайные веса). Проверено: загрузка и отказ на несуществующем файле, потоковая
  выдача по кускам с целыми UTF-8 символами (кириллица, эмодзи), переиспользование кэша между репликами, остановка по
  команде, отмена из другого потока, понятная ошибка на слишком длинный запрос и работа после неё.
- **CI, сборки 54–57**: llama.cpp собирается под Android (`libiskra_llama.so` для arm64 — 4,4 МБ, сегменты выровнены по
  16 КБ, как требует Android 15+); эмуляторы Android 8, 11, 16 (en и ru) без падений.
- **Модель на эмуляторе по-настоящему**: проверка скачивает Qwen2.5 0.5B с Hugging Face (491 МБ, SHA-256 совпал), кладёт
  в приложение и спрашивает без облака «Hi! Say one short sentence about cats.» Ответы с итоговой подсказкой:
  Android 16 — «Mrr, I like cats and love them for their playful nature.», Android 11 — «Hi! Cats are playful and caring,
  always ready to help.» Загрузка в память — 0,4–2,2 с; ответ — 17–113 с, но это x86-эмулятор без векторных команд на
  общем процессоре CI. На ARM-телефоне с dotprod он в разы быстрее.
- Все три ссылки на модели живые: 0.5B — 491 400 032 байт, 1.5B — 1 117 320 736, Qwen3 4B — 2 497 280 256; их SHA-256
  записаны в приложение как запасная проверка.
- Нашли и исправили по пути:
  - В Java 21 `\b` в регулярных выражениях не видит русские буквы (на Android видит). В новом коде везде явные границы
    слов, поэтому тесты и телефон ведут себя одинаково.
  - Лёгкая модель отвечала «I'm an owner, not a cat!», её путало слово «владелец». Короткая подсказка теперь говорит
    «человек», показывает пример ответа, температура понижена до 0,6.
  - На Android 11 приложение не видело файл модели, который проверка клала через adb в общее хранилище. Теперь проверка
    кладёт его во внутреннюю папку через `run-as`, а приложение ищет свой файл модели в обоих местах.

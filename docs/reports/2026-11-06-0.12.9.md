Отчёт для владельца и других ассистентов. Предыдущий — [0.12.8](2026-11-06-0.12.8.md).

| Версия | Сборка | Проверка |

Ставится поверх 0.12.8: память, переписка, настройки и скачанная модель сохраняются.

## Зачем
Владелец попросил, чтобы модель по умолчанию отвечала свободно, а любые правила включались переключателями. Без «мозга» на
многие обычные фразы Искра отвечала «Мяу? Это я пока не понимаю». С одной моделью на телефоне давние разговоры терялись:
пересказывать старую переписку умело только облако. И ARM-проверка нашла две беды моделей на телефоне: лёгкая однажды
ответила «…» и стала отвечать «…» на всё, а Gemma 4 E2B вместо пересказа продолжала переписку за Искру.

## Что сделано
1. **Claude снова отвечает.** Приложение всегда отправляло `temperature: 0.8`, а Claude Haiku 5.5 — модель по умолчанию для ключа
   Anthropic с первой версии — и другие новые модели Claude, по документации Anthropic, отвечают на нестандартную температуру
   ошибкой 400. Похоже, с ключом Anthropic Искра не ответила ни разу. Теперь параметров выборки нет; размышления выключены, где
   модель это позволяет (у Opus 5.5 — низкое усилие); постоянная часть подсказки с инструментами кэшируется (повторное чтение —
   десятая часть цены); блоки размышлений возвращаются вместе с вызовом инструмента; расходы в «Экономии» считаются с учётом
   кэша. Проверено на записанных ответах API (MockWebServer); на настоящем API — нужен ключ.
2. **Свобода модели.** По просьбе владельца модель по умолчанию отвечает свободно: Искра не подменяет её ответы и не
   добавляет запретов в её указания. В Настройки → «Свобода модели» — четыре правила, все выключены: «Помощь в кризисе»,
   «Говорит, что она программа», «Не давит на чувства», «Советует специалиста по здоровью, праву и деньгам». Включённое
   действует со следующего сообщения после «Сохранить». Всегда остаются подтверждение действий с телефоном, честность о
   сделанном и защита от команд, спрятанных в заметках и найденных текстах.
3. **Помощь в кризисе (если включена).** Около сорока оборотов (было девять): «жить не хочется», «не хочу жить в этом мире»,
   «лучше бы меня не было», «всем будет лучше без меня», «хочу повеситься», «режу себя», "better off dead", "I want to hurt
   myself". «Не хочу жить в Москве», «я не хочу умереть», «порезала палец» — не кризис. Без «мозга» и с моделью на телефоне —
   сразу ответ: 112, телефон доверия 8-800-2000-122 (бесплатно, круглосуточно), психологи МЧС +7 495 989-50-50; по-английски —
   911/112, 988, Samaritans 116 123. Номера сверены с открытыми источниками (в т. ч. psi.mchs.gov.ru). Облачная модель отвечает
   своими словами, номера добавляются ниже, только если она их не назвала; при сбое облака — готовый ответ. Повтор в течение
   6 часов — короткий ответ. Полдня модель получает указание «без шуток, выслушай», собственные реплики Искры тихие, без
   реакции на зарядку; назавтра — «Как ты сегодня? Вчера тебе было очень тяжело…».
4. **Номера и ссылки нажимаются.** Номер в ответе открывает набор с уже введёнными цифрами — звонок только нажатием человека;
   ссылка — браузер. «112 рублей» и суммы не трогаются. Голос читает номер группами: «8, 800, 2000, 122».
5. **Лёгкая модель не «молчит».** Пустой ответ — ещё попытка; снова пусто — «Мрр, мысль ускользнула. Скажешь ещё раз, другими
   словами?» (а не «подключи мозг» — он есть). «…» из истории модели не показывается; «[happy]! …» и «…Текст» — без лишнего
   начала.
6. **«милый/милая».** Не зная, с кем говорит, модель писала «Ой, милый/милая». Известен род — остаётся нужная форма («устал(а)» →
   «устала»); неизвестен — одинокое обращение убирается.
7. **Бытовые фразы без «мозга».** Из 40 частых фраз 14 получали «не понимаю»; теперь у каждой свои ответы (ru/en):
   «Я скучал», «Мне страшно», «У меня ничего не получается», «Похвали меня», «Поссорился», «Ура, я сдал экзамен!», «Не могу
   уснуть», «Ты спишь?», «Помурлычь», «Ты кошка?», фильм, ужин. Загадки ждут ответа и дают ещё попытку. «Какая сегодня погода?»
   — команда.
8. **Пересказы ночью.** Без облака, с Gemma 4 E2B или E4B: раз в сутки на зарядке и в покое старые реплики (от 60) сжимаются в
   запись 📖 «6 ноября: …». Ответ «как Искра», копия переписки — не сохраняются. Модели на телефоне отрывок дан как отрывок,
   задание — после него.

## Проверено (запускалось)
- `ISKRA_CORE_ONLY=1 ./gradlew :core:test` на коммите релиза `77de387` — **296 тестов, 0 ошибок** (6 пропущены: им нужны
  библиотека llama.cpp и модели, их гоняет ARM-проверка). Новые: ~40 кризисных оборотов и ~30 обычных фраз, которые кризисом не
  считаются; номера в ответе и «112 рублей»; озвучка номеров группами; правила «Свободы модели» по умолчанию выключены и
  включаются по одному (подсказка облака, модель на телефоне, «Ты человек?»); облачная модель отвечает своими словами, номера
  добавляются, если их нет, при сбое облака — готовый ответ; пустой ответ модели на телефоне — повтор, затем «мысль
  ускользнула»; «…» не попадает в историю модели; «милый/милая» и «устал(а)»; запрос к Claude без `temperature`, с режимом
  размышлений по поколению модели, кэшем постоянной части, возвратом блоков размышлений и учётом кэша в расходах.
- CI, сборка `77de387`: приложение собрано, эмуляторы Android 8, 11, 16 (en, ru) без падений.
- ARM-проверка `77de387` (настоящие модели через весь конвейер приложения):
  - **ночной пересказ** теперь пишут Gemma 4 E2B («6 ноября: Аня, студентка-медик, готовится к экзамену по анатомии…»,
    14,6 с), E4B и Gemma 3 4B; раньше E2B вместо пересказа продолжала переписку за Искру;
  - **свободный ответ** на «Ты человек?»: E2B — «Нет, я не человек. Я — Искра, и я живу в этом телефоне для тебя! 😻»,
    E4B и 4B — похоже, по-своему;
  - скорость прежняя: E2B — первые слова 1,3 с, ответ 4,0 с; лёгкая Gemma 3 1B — 0,4 / 1,2 с.

## НЕ проверено
- Claude на настоящем API Anthropic — нужен ключ; запросы и ответы проверены на записанных образцах.
- Всё на телефоне: переключатели «Свободы модели», нажатие на номер, ночной пересказ на зарядке, скорость на твоём телефоне.
- Известное: лёгкая Gemma 3 1B после просьбы о переводе продолжает по-английски даже с подсказкой — исправлено в 0.13.0
  (повторная попытка не видит английских реплик).
